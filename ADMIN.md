# Админка Learnly

Страница **https://learnly.space/admin/**: здесь можно добавлять, изменять, скрывать и удалять преподавателей, курсы и экзамены. Сервер не нужен — изменения сохраняются коммитом прямо в этот репозиторий, а GitHub Pages обновляет сайт через 1–2 минуты.

## Первая настройка (один раз, делает владелец репозитория)

1. Откройте `admin/config.js` и впишите в `owner` своё имя пользователя (или организации) на GitHub. Проверьте `repo` и `branch`.
2. Если админ — не владелец репозитория, добавьте его: **Settings → Collaborators → Add people**.

## Вход для админа

1. Войдите в GitHub и откройте https://github.com/settings/personal-access-tokens/new
2. **Token name**: «Админка Learnly». **Expiration**: до 1 года.
3. **Repository access** → *Only select repositories* → репозиторий сайта.
4. **Permissions → Repository permissions → Contents → Read and write**. Больше ничего не нужно.
5. **Generate token**, скопируйте его и вставьте на странице `/admin/`.

Токен хранится только в браузере админа и отправляется только на `api.github.com`. Если токен утёк — удалите его на той же странице GitHub.

## Как пользоваться

- Все правки сначала попадают в **черновик**. На сайте ничего не меняется, пока не нажата **«Опубликовать»**.
- Тексты заполняются на 4 языках (EN / RU / TJ / AR). Точка на вкладке языка: зелёная — заполнено, жёлтая — частично. Пустые поля на сайте покажутся на английском.
- **«Скрыть на сайте»** убирает карточку с сайта, но оставляет её в админке — удобно для отпусков.
- Фото обрезается до квадрата и уменьшается до 640×640 автоматически.
- Если два человека редактировали одновременно, второй получит предупреждение и ничего не перезапишет.

## Если что-то пошло не так

Каждая публикация — отдельный коммит «Админка: …». Откатить можно на GitHub: **Commits** → нужный коммит → **Revert**.

## Где лежат данные

- `data/teachers.json` — преподаватели
- `data/courses.json` — курсы и экзамены
- `img/teachers/` — фото преподавателей
