Вход

Изменения сохраняются прямо в репозиторий сайта на GitHub. Сайт обновится через 1–2 минуты после публикации.

Как получить токен — в инструкции ниже. Токен хранится только в этом браузере и отправляется только на api.github.com.

Как получить токен (один раз, ~3 минуты)
  1. Войдите в GitHub под аккаунтом, у которого есть доступ к репозиторию сайта.
  2. Откройте Settings → Developer settings → Fine-grained tokens → Generate new token.
  3. Название — например, «Админка Learnly». Срок действия — до года.
  4. Repository access → Only select repositories → выберите репозиторий сайта.
  5. Permissions → Repository permissions → Contents → Read and write. Больше ничего не включайте.
  6. Нажмите Generate token, скопируйте его и вставьте сюда.

Если токен утёк, удалите его на той же странице GitHub — доступ сразу пропадёт.
