2Create your sign-in

At least 10 characters. It encrypts your GitHub token on this device, so it can't be recovered — if you forget it, you'll set up again with a token.

How to get a token (about 3 minutes)
  1. Sign in to GitHub with an account that has access to the website repository.
  2. Open Settings → Developer settings → Fine-grained tokens → Generate new token.
  3. Name it, for example “Learnly admin”. Set the expiration to up to one year.
  4. Repository access → Only select repositories → choose the website repository.
  5. Permissions → Repository permissions → Contents → Read and write. Nothing else is needed.
  6. Click Generate token, copy it and paste it above.

If the token ever leaks, delete it on the same GitHub page and access stops immediately.
